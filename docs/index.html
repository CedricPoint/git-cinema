git cinema 🎬

One command turns any git repository into a film. Directories grow into a living tree, files light up as they change, contributors fly around firing at their code. Export it as a 1080p MP4 and post it.

▶Express17 years · 5,637 commits · 383 contributors ▶Vitelast 3 years · 3,648 commits · 623 contributors

Make your own

git clone https://github.com/CedricPoint/git-cinema.git
node git-cinema/git-cinema.js path/to/your/repo --open

Node.js 18+ and git. No dependencies, nothing to install, nothing leaves your machine. You get one HTML file you can open, share or host anywhere.

● Record 1080pExports the whole film as MP4 (or WebM), straight from the browser.
⏯ Scrub through timeSeek, pause, change speed. Space, ← →, + −.
🕶 Anonymize--anonymize replaces names with “Dev 1, Dev 2…” for private repos.
⚡ FastExpress's 17 years render in 0.2 s, into a 200 KB file.
